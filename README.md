# Jumentolandia | Agencia de Innovación Narrativa

Jumentolandia fusiona marketing político, storytelling de marca y desarrollo interactivo.

## Descripción

Este proyecto es el sitio web de Jumentolandia, una agencia que combina estrategia política con la adrenalina de los videojuegos para crear narrativas inmersivas.

## Tecnologías

- **HTML5**
- **CSS3** (Bootstrap 5, Custom CSS)
- **JavaScript** (jQuery, Swiper, AOS, Particles.js)

## Características

- **Diseño Responsivo**: Adaptado a dispositivos móviles y de escritorio.
- **Animaciones**: Uso de AOS y Particles.js para una experiencia visual dinámica.
- **Modo Oscuro/Claro**: Toggle de tema integrado.
- **Carrusel de Proyectos**: Visualización interactiva de proyectos destacados.

## Instalación

Simplemente clona el repositorio y abre `index.html` en tu navegador.

```bash
git clone https://github.com/jumento/jumentolandia-web.git
cd jumentolandia-web
# Abre index.html
```
